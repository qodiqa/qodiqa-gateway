# Roadmap

Planned work. Nothing on this page is part of the supported feature set today.

- **Retention policy type.** A policy rule that sets audit retention per data category and is applied automatically. Retention of audit data is configured today with the audit retention policies (`docs/guides/DATA_GOVERNANCE.md`).
- **Restart-safe revocation de-duplication.** Persist the revocation event log so a subscriber restart never re-processes an event.
- **Persistent anomaly baselines** for the alerting module.
